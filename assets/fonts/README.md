# Fonts

`ProggyClean.ttf` is bundled for the compact Linoria UI text style.

- Source: https://github.com/i77lhm/storage/blob/refs/heads/main/fonts/ProggyClean.ttf
- Runtime path: `assets/fonts/ProggyClean.ttf`
- SHA-256: `527d2a443ce051f93f7e77b855609722b8cb220a9f104b4aa037be5c90b71324`

When executor custom-font APIs are unavailable, the library falls back to Roblox's built-in `Code` font.
